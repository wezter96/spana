# Privacy Policy

The Spana documentation website (`https://spana.antonwester.se`) is a static documentation site.

- **No tracking cookies:** This site does not set advertising, analytics, or cross-site tracking cookies.
- **No personal data collection:** We do not collect, store, sell, or share personal data, form submissions, or user profiles.
- **Hosting logs:** Static assets are served via GitHub Pages (and Cloudflare DNS/CDN), which may process standard HTTP request metadata (such as IP address and user agent) solely to deliver and protect the service.
- **Open-source CLI:** The `spana` CLI runs locally on your machine and does not phone home or send telemetry by default.

For privacy or security questions, open an issue or private advisory on [GitHub](https://github.com/wezter96/spana).
