# Security Policy

## Supported Versions

Security fixes are applied to the latest published `spana` release on `main`.

## Reporting a Vulnerability

Please do not open public GitHub issues for security vulnerabilities.

Instead, report vulnerabilities privately via GitHub Security Advisories:

- https://github.com/wezter96/spana/security/advisories/new

We aim to acknowledge reports within 72 hours and provide a remediation plan once confirmed.
